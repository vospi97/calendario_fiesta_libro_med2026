# Calendario Fiesta del Libro y la Cultura Medellín 2026

Este calendario está diseñado para ayudarte a organizar tu agenda de la Fiesta del Libro y la Cultura Medellín 2026. Ha sido generado con asistencia de herramientas automatizadas (IA) y, aunque es fiel a la realidad, no constituye una fuente oficial.

Úsalo como guía práctica para no perderte los eventos, pero si necesitas confirmación absoluta (horarios, sedes o cambios de última hora), te recomiendo consultar los medios oficiales.

## Enlaces para suscribirte con un clic (según tu caso):

- **iPhone, iPad o Mac:** Haz clic [aquí](webcal://raw.githubusercontent.com/vospi97/calendario_fiesta_libro_med2026/refs/heads/main/Fiesta_del_Libro_2026.ics) y se abrirá tu calendario para agregarlo.
- **Google Calendar (web):** Haz clic [aquí](https://calendar.google.com/calendar/r?cid=https%3A%2F%2Fraw.githubusercontent.com%2Fvospi97%2Fcalendario_fiesta_libro_med2026%2Frefs%2Fheads%2Fmain%2FFiesta_del_Libro_2026.ics) para agregarlo directamente.

Si ninguno de esos funciona para ti (por ejemplo, usas Outlook o algún calendario en Android), copia esta URL y pégala en la opción de "suscribir por URL" de tu aplicación:

https://raw.githubusercontent.com/vospi97/calendario_fiesta_libro_med2026/refs/heads/main/Fiesta_del_Libro_2026.ics

## ¿Cómo se hace en cada calendario?

- **Google Calendar:** Ajustes → Otros calendarios → Añadir mediante URL.
- **Outlook:** Agregar calendario → Suscribirse desde Internet.
- **Apple:** Ajustes → Calendario → Cuentas → Añadir cuenta suscrita.
